### 1. Executive Summary

In Phase 3B.1, Audit 5 uncovered a critical defect in `ResearchEvaluator.evaluate_regimes`:
1. The evaluator hardcoded `sample_df = list(data_dict.values())[0]` (AAPL).
2. All 575 portfolio trades were matched against the AAPL timestamp dictionary.
3. Because other assets had non-matching timestamps, **491 out of 575 trades failed to match** and were dumped into the `.get()` default bucket (`RANGING` direction and `NORMAL` volatility).
4. Volatility percentiles were computed on the entire multi-year series (`norm_vol.quantile(0.33)` and `0.67`), introducing full-sample lookahead bias.

In Phase 3B.2 Workstream 3, `ResearchEvaluator` was refactored to enforce:
- Independent point-in-time regime feature calculation for each asset.
- Strict matching via composite key: `(asset_symbol, entry_timestamp)`.
- Strictly backward-looking rolling quantiles (zero full-sample lookahead).
- Explicit tracking of unmatched trades with zero silent fallbacks to `RANGING` or `NORMAL`.

### 2. Architectural Refactoring & Mathematical Design

#### 2.1 Per-Asset Point-in-Time Rolling Quantiles
In `compute_asset_regime_features(df, rolling_window=250)`:
1. Normalized ATR is computed strictly on completed bars:
   $$\text{NormVol}_t = \frac{\text{ATR}_{20, t}}{\text{Close}_t} \times 100$$
2. Volatility thresholds are computed over a backward-looking rolling window:
   $$P_{33, t} = \text{Quantile}_{0.33}\left(\text{NormVol}_{t-W:t}\right), \quad P_{67, t} = \text{Quantile}_{0.67}\left(\text{NormVol}_{t-W:t}\right)$$
   Where $W = 250$ bars ($\text{min\_periods} = 20$).
   - If $\text{NormVol}_t \le P_{33, t} \rightarrow \mathbf{CALM}$
   - If $P_{33, t} < \text{NormVol}_t \le P_{67, t} \rightarrow \mathbf{NORMAL}$
   - If $\text{NormVol}_t > P_{67, t} \rightarrow \mathbf{HIGH}$
   - If $t < \text{min\_periods} \rightarrow \mathbf{WARMUP\_UNCLASSIFIED}$
3. Future bars $t+1 \dots T$ have **zero influence** on the classification of bar $t$.

#### 2.2 Directional Regime Definition (ADX)
Directional strength is classified via Wilder's 14-period ADX:
- $\text{ADX}_t \ge 25.0 \rightarrow \mathbf{TRENDING}$ (sustained directional impulse)
- $\text{ADX}_t < 20.0 \rightarrow \mathbf{RANGING}$ (consolidation chop)
- $20.0 \le \text{ADX}_t < 25.0 \rightarrow \mathbf{NEUTRAL}$ (transition zone)

#### 2.3 Composite Matching Engine
```python
# Composite dictionary keyed by (symbol, entry_time)
composite_regime_map[(symbol, entry_time_str)] = {
    "vol_regime": row["vol_regime"],
    "dir_regime": row["dir_regime"],
    "feature_time": entry_time_str
}
```
When evaluating trade $t$:
```python
key = (trade["symbol"], trade["entry_time"])
info = composite_regime_map.get(key)
if info is None:
    unmatched_trades.append(trade)  # Recorded explicitly, never defaulted!
```
